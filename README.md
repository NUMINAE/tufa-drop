# TUFA · Drop 01 · Pink City

A concept streetwear drop for Yerevan, designed and built by [Numinae Studio](https://t.me/bynuminae).

- **Drop page:** https://numinae.github.io/tufa-drop/
- **Telegram Mini App (demo outside Telegram):** https://numinae.github.io/tufa-drop/miniapp/

Plain HTML, CSS and JavaScript, no framework. Product and lookbook images were generated locally with Flux 2.

TUFA is a fictional brand. Nothing here is for sale.
